# 📚 Book Scraper

A Python web scraping project that extracts book information
from [Books to Scrape](https://books.toscrape.com/).

The project demonstrates automated pagination, HTML parsing,
structured data extraction, and CSV data export.

## ✨ Features

- Extracts book titles
- Collects book prices
- Retrieves star ratings
- Extracts availability information
- Supports multi-page scraping
- Exports collected data to CSV

## 🛠️ Technologies

- Python
- Requests
- BeautifulSoup
- HTML parsing
- CSV
